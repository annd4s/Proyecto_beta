
# 🐾 Fundación Patitas Felices

> *"Transformando vidas, una patita a la vez."*

Maqueta web institucional y de adopción para una fundación de protección animal.
**HTML5 + CSS3 nativo · 100% responsive · Sin JavaScript**

---

## 📖 Descripción

Proyecto académico que simula la plataforma digital de una fundación dedicada al rescate, protección y adopción responsable de animales. Toda la interactividad (carruseles, validación de formularios, animaciones) está implementada **exclusivamente con CSS puro**.

## ✨ Características

- 🏠 **Home:** hero con CTA dual, carrusel automático (3s), secciones destacadas y testimonios.
- 🎯 **Visión y Misión:** layout adaptable con iconografía dedicada.
- 🖼️ **Galería:** mosaico interactivo con hover y captions.
- 🐕 **Catálogo:** grid de 8 animales con estado dinámico y perfil detallado + carrusel de relacionados.
- ✉️ **Formulario:** validación visual 100% CSS (`:valid`, `:invalid`, `.error`, `.success`).
- 🔻 **Footer:** Flexbox con datos legales y enlaces.

---

## 🛠 Stack

HTML5 · CSS3 (Grid, Flexbox, `@keyframes`, media queries) · Google Fonts (*DM Sans* + *Playfair Display*) · Font Awesome 6.7.2
